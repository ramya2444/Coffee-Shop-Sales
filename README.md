# ☕ Coffee Shop Sales Dashboard

## 📌 Project Overview

The **Coffee Shop Sales Dashboard** is an interactive data analytics project designed to analyze retail coffee shop sales data and generate actionable business insights.

This dashboard helps stakeholders monitor:
- Sales performance
- Customer footfall
- Product demand
- Peak business hours
- Store-wise performance
- Product category distribution

The project was built using **Microsoft Excel** with Pivot Tables, Charts, KPI Cards, and Interactive Slicers.

# 🎯 Objectives

The main objective of this project is to analyze coffee shop sales data and answer key business questions such as:

- How do sales vary by day and hour?
- What are the peak sales periods?
- Which products generate the highest revenue?
- Which store location performs best?
- What is the average bill per customer?
- How do product categories contribute to sales?

# 🔍 Business Insights

- Morning hours generate the highest sales volume.
- Coffee contributes the largest percentage of overall sales.
- Hell’s Kitchen store records the highest revenue.
- Weekdays perform better than weekends in terms of orders.
- Large and Regular drink sizes are the most preferred.
